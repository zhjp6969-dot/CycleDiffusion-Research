# Research figures

The three source-driven figures are generated by
[`make_research_figures.py`](../scripts/make_research_figures.py).
Each has a PNG preview and PDF/SVG vector exports. PNG uses 300 dpi; SVG retains
editable text and PDF embeds TrueType fonts.

## Homepage overview

[`research_overview.png`](research_overview.png) is an AI-assisted conceptual
illustration reviewed against the project summaries. It depicts the implemented
cycle-gradient branch, discovery-to-confirmation sequence, and evaluation-only
path-length study; it is not a complete model architecture or a quantitative plot.
Waveform-like icons are schematic, not measured audio. This raster illustration
is not regenerated by the plotting script and has no vector export.

## Design reference

The style follows Chen Liu's
[figures4papers](https://github.com/ChenLiu-1996/figures4papers), specifically its
[Scientific Figure Making skill](https://github.com/ChenLiu-1996/figures4papers/blob/main/scientific-figure-making/SKILL.md),
[design theory](https://github.com/ChenLiu-1996/figures4papers/blob/main/scientific-figure-making/references/design-theory.md),
and [API conventions](https://github.com/ChenLiu-1996/figures4papers/blob/main/scientific-figure-making/references/api.md),
consulted on 2026-09-30. Original plotting code uses the reference's sans-serif
typography, blue/teal/red palette, minimal spines, and vector-export conventions.
No external example data or figure images are incorporated.

## Regenerate

```bash
python -m pip install -r requirements-figures.txt
python scripts/verify_research_summary.py
python scripts/make_research_figures.py
```

The verifier checks summaries, confirmation unit means, and path-length cluster
means. It does not
recompute bootstrap intervals or recover unavailable raw audio/evaluator records.

## Sources and interpretation

- **research_evidence_chain**: conceptual research sequence, with no numeric
  axis. Confirmation uses a different cohort; the final path-length experiment
  returns to the original discovery cohort.
- **reliability_effects**: joint discovery values from
  [Layer 6 paired results](../data/processed/layer6_formal_eval_paired_comparisons.csv),
  content-only discovery values from
  [Layer 4 ablation](../data/processed/layer4_full_primary_comparisons.csv),
  and confirmation values from
  [Layer 10 pooled effects](../data/processed/layer10_confirmation/analysis/layer10_pooled_effects.csv).
  Each point is candidate minus uniform; whiskers reproduce the stored 95%
  bootstrap interval. All shown continuations use lambda 1. Shapes distinguish
  rows in grayscale. Higher identity is favorable; lower content error is
  favorable. There is no cross-cohort pooled estimate.
- **path_length_effects**: the two co-primary three-minus-two contrasts from
  [Layer 8b results](../data/processed/layer8_path_length/analysis/path_length_contrasts.csv).
  Both paths are compared with the direct anchor; intermediate orders are
  averaged. Word edit distance measures anchor-to-output ASR divergence.
  Signed robust-content-error change measures change in the transcript-based
  bounded error proxy. Higher values are harmful for both; they are distinct
  metrics, not two measurements of ordinary WER.

The robust content proxy is max(min(WER, 1), min(CER, 1)). Identity is target
minus source WavLM cosine similarity, not a human similarity score.
Discovery intervals use 20 source clusters sharing four speakers. Confirmation
uses seed-then-source-unit resampling with only three seeds and four new speakers.
These intervals do not establish population-level speaker generalization.
